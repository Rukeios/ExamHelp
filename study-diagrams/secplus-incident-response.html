Incident response: the order matters

Security+ (SY0-701) uses these seven steps. Exam questions ask "what comes next?" or "what should you do FIRST?", so learn the order and the one-line job of each step.

1
Preparation
Get ready before anything happens.
Write the IR plan and playbooks, pick the team, set up tools and logging, train and run exercises.
e.g. a tabletop exercise on "what if ransomware hits payroll?"
2
Detection
Notice that something's wrong.
Alerts, logs, a SIEM, an IDS, or a user reporting something strange.
e.g. the SIEM flags 500 failed logins in a minute.
3
Analysis
Is it real, and how bad is it?
Confirm it isn't a false positive, find its scope and impact, and prioritize. Start preserving evidence.
e.g. three laptops have the same malware.
4
Containment
Stop it from spreading.
Isolate infected hosts, disable compromised accounts, segment the network. Limit the damage first.
e.g. pull the three laptops off the network.
5
Eradication
Get rid of the cause.
Remove the malware, close the hole that let it in, and reset stolen credentials.
e.g. reimage the laptops and patch the exploited flaw.
6
Recovery
Get back to normal, safely.
Restore from clean backups, bring systems back online, and watch closely in case it returns.
e.g. laptops return; monitoring stays heightened for two weeks.
7
Lessons learned
What would we do differently?
Root cause, a written report, and updates to the plan, tools and training.
e.g. "add MFA to VPN" goes into the plan.
↺ Recovery can loop back to Detection if it comes back
↺ Lessons learned feed back into Preparation: the cycle never really ends
THE SAME PROCESS IN NIST SP 800-61 (an older 4-phase grouping you'll also see)
Preparationstep 1
Detection & Analysissteps 2–3
Containment, Eradication & Recoverysteps 4–6 · can loop back to Detection & Analysis
Post-Incident Activitystep 7
Memory line: "Please Don't Attack, Can Everyone Relax Later?" Preparation, Detection, Analysis, Containment, Eradication, Recovery, Lessons learned.
The trap: after you confirm an infection, the next step is containment, not cleanup. Stop the spread first, then remove it. Wiping a machine before containing and preserving evidence is the wrong answer.
Clue words: "isolate, disconnect, quarantine" = containment · "remove, reimage, patch the hole" = eradication · "restore, bring back online" = recovery · "root cause, update the plan" = lessons learned.
