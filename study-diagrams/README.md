# Study diagrams

These are one-page study diagrams for SC-900 and Security+. They're published with the site at `/study-diagrams/`.

- Each diagram is a standalone HTML page, with a PNG preview in `img/`.
- `level7-walkthrough.md` and `entra-signin-walkthrough.md` are written walkthroughs of two of the diagrams.
- **Copyright rule:** when a diagram is based on a class slide, we remake it from the public standard (Microsoft Learn, CompTIA objectives, NIST) in our own layout, wording and examples. We never copy a slide's artwork, layout or phrasing.
- **Accuracy:** the SC-900 facts match the Rukeios Study lessons, which were checked against Microsoft Learn on 3 Oct 2026. No human expert has reviewed the diagrams.
