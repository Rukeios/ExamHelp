Where attacks hit along the path

Security+ (SY0-701). Follow a user's request from their laptop to a web app. Each stop shows the attacks that happen there (red), what gives them away, and the control that stops them (green).

1. The airwaves

Laptop to access point
Evil twinFake AP copying your network name.Stop: WPA3-Enterprise / 802.1X, user training, wireless IDS
Rogue APUnapproved AP plugged into your network.Stop: 802.1X on ports, wireless scans
DeauthenticationClients kicked off so the handshake can be captured.Stop: WPA3 (protected management frames)
JammingRadio noise blocks everyone.Stop: find the source; it's an availability attack

2. The local network

Switches, the gateway
ARP poisoningFake IP-to-MAC answers make traffic flow through the attacker.Stop: dynamic ARP inspection, segmentation
MAC floodingSwitch table overflows, so it floods traffic everywhere.Stop: port security
On-pathAttacker reads or changes traffic between two parties.Stop: encryption (TLS, VPN), certificate checks

3. Name lookup

DNS
DNS poisoningResolver cache holds a fake answer, so the right name leads to the wrong server.Stop: DNSSEC
Domain hijackingControl of the domain registration is stolen.Stop: registrar lock, MFA on the registrar account
TyposquattingLookalike names catch typos.Stop: user training, register common misspellings

4. The internet edge

Your public address
DDoSA flood from many sources. Reflected: forged source so replies hit the victim. Amplified: tiny request, huge reply (DNS, NTP).Stop: DDoS protection service, rate limiting, CDN
ReplayCaptured traffic resent later.Stop: timestamps, nonces, session tokens
Credential replayStolen hash or token reused (pass-the-hash).Stop: MFA, Kerberos, short-lived tokens

5. The web app

Requests and the database
SQL injectionDatabase commands typed into input fields.Stop: parameterized queries, input validation, WAF
XSSAttacker's script runs in other users' browsers.Stop: output encoding, input validation, WAF
CSRF / SSRFCSRF: the user's browser sends a forged request. SSRF: the server is tricked into making requests.Stop: anti-CSRF tokens · allow-list outbound requests
Directory traversal../../ to reach files outside the web folder.Stop: input validation, least privilege
ARP vs DNS poisoning: ARP fakes the hardware address and stays on the local network. DNS fakes the name answer and can reach users anywhere.
Evil twin vs rogue AP: an evil twin pretends to be your network to lure users. A rogue AP is a real but unapproved access point on your network.
CSRF vs SSRF: look at who sends the bad request. The user's browser means CSRF. The server means SSRF.
