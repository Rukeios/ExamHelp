# v2.3.4: Instructor view

A setting in Plan settings (self-paced mode only) that opens every level, mock exam and boss without earning them, for a teacher reviewing the material or a class demo. Built on top of v2.3.3, so merging 2.3.4 also brings in the exam-conditions mock.

## How it works: a sandbox
- **Turning it on** stores a copy of the learner's state and attempts in `sprint.v2.instructor`, after an inline confirmation that explains what happens. If the browser has no room for the copy, it stays off and says why.
- **While it's on,** the app works normally, so quizzes, the mock and bosses can all be run. Every level, the mock and every boss are open: `accessDay()` returns the last level of the program in place of `unlockedDay()` wherever content is gated (the level navigator, practice pools, boss availability, the "Next level" button), `bossOpen()` returns true, and `mockUnlockStatus()` reports unlocked. "Current level" displays still use the real `unlockedDay()`.
- **Turning it off** writes the stored copy back and reloads the page, so nothing done in Instructor view is kept: levels, XP, history, Review, bosses, flashcards, campaign, everything.
- **A banner** at the top of every page says it's on, gives the date of the stored copy and has a "Turn off Instructor view" button. It stays on across reloads.
- **Refused while it's on** (`instrGuard()`): device transfer, backup download and share, restore, import, the instructor summary download and copy. Each would otherwise carry the sandbox instead of the real progress. The banner shows the reason.
- **Not offered** in campaign mode or when progress syncs to an account, since the sandbox only covers this browser.
- **No password.** Any code in a web page is readable, so it would only pretend to protect something, and the mode grants no credit.

## Also fixed
The Plan settings panel opened right-aligned to its button. Where the header wraps and the button sits on the left (most phones), the panel ran off the left edge: at 360 px its left edge was at −185 px. `fitSettings()` now keeps it 16 px inside the screen at every width. The settings rows also no longer print a stray "null" when a row is absent.
