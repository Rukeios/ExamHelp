## What changed
- New data files (all loaded by index.html and tools/check-content.js): data-cn-sec-1..4 (notes + recall cards), data-cn-sec-N-cmp (comparisons), data-cn-sec-N-scen (scenarios), data-lessons-sec-1..4 (interactive lessons and review casebooks), data-xf-sec-1..4 (exam-style items).

- index.html: removed the single-course fallback link and the "30-45 minutes" claim; script tags for the new files.
- tools/check-content.js: loads the Security+ files, validates lessons (sections, notes, practice, casebook links, check pool size), requires scenario day/track agreement, and accepts Messer/CompTIA hosts.
