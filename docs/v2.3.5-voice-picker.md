# 2.3.5: Voice picker for Read aloud

**Where:** Accessibility → Reading → Voice (shown when Read aloud is on).

## What it does
- Lists the speech voices installed on the device (`speechSynthesis.getVoices()`), English first, then the other languages.
- **Automatic** (the default) picks the most natural-sounding English voice instead of the browser default. It ranks Natural, Neural, Online and Enhanced voices first, then Google voices and en-US. Novelty voices (macOS Zarvox and similar) and eSpeak are ranked last.
- **Try it** reads a sample sentence with the selected voice and speed.
- Read aloud buttons use the selected voice, and the utterance's `lang` is set from that voice.

## Storage
- Saved as `a11y.voice` (a voiceURI string; `""` means Automatic) in `sprint.v2.a11y`, so it is included in backups like the other accessibility settings.
- Voices differ for each device and browser. If the saved voice isn't installed, Automatic is used and the dialog explains why. The saved choice is kept, so moving back to the original device restores it.
- **Reset to defaults** clears the choice.

## Edge cases
- Voices load asynchronously in Chrome. The dialog re-renders on `voiceschanged`, and shows a "still loading" message until voices arrive.
- The dialog's Tab focus trap now includes `select` elements.

Test: `t235.py` (uses fake voices, at 1280 and 375 widths).
