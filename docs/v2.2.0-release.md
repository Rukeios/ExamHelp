# Rukeios Study v2.2.0: visual and UX update

A visual and layout release. It adds no learning modes, and it doesn't change scoring, question IDs, or the save format (storage keys and backups are unchanged).

## Brand
- The name is now **Rukeios Study**, with the tagline "Your certification field guide". RJ approved the change.
- Every name string comes from one `BRAND` object in `index.html`. The static `<title>`, meta tags and header markup repeat the name so the first paint is correct.
- Logo files in `assets/brand/` were cut from RJ's brand sheet:
  - wordmark lockups for light and dark backgrounds
  - the R mark
  - a 512×512 app icon, a 180×180 Apple touch icon, and 32px and 16px favicons
  - a 1200×630 social preview
- These are kept the same on purpose so nobody's profile empties:
  - the `sprint.v2` storage keys
  - the `app:"ExamHelp"` field inside exported files (a new `brand` field carries the current name)
- Backups from ExamHelp, CertificationNation and Rukeios Study all import.
- People who already have a profile see a one-time notice: "ExamHelp/CertificationNation is now Rukeios Study".
- The repository name and live URL are unchanged.

## Design system
- **Colors:** taken from the logo.
  - Light theme: paper page `#F5F2EC`, white raised surfaces, navy ink `#0F2340`, brand teal for the primary action and for progress.
  - SC-900 is coded blue and Security+ bronze.
  - The dark theme uses matching deep navy.
- **Type:**
  - Outfit for display text and headings; it echoes the wordmark.
  - IBM Plex Sans for reading.
  - Barlow Condensed only for the "challenge" voice: boss names and the campaign title.
- **Fonts are self-hosted** in `assets/fonts` (OFL, subset WOFF, about 120 KB), so the page no longer calls Google Fonts.
- **Surfaces:** study pages are calm paper. The boss encounter and the campaign door are the only dark, art-led surfaces in both themes.
- **Dark-mode backgrounds:** study pages no longer sit on background art; the Arena keeps its arena scene.

## Screens
- **Header:** one progression display, "Level X of N", with a bar. Rank, XP and run/tier moved to the Arena ("Your record") and to the top of Progress.
- **Home:**
  - A single lead action: paused quiz, then due review, then the current lesson.
  - The lead shows what the lesson covers and has one primary button.
  - Beside it: a next-challenge card with the correct boss artwork and status, plus a compact list for review, flashcards, the five-minute sprint and recent activity. Empty activity collapses to one line.
  - The domain overview sits below, as rows.
- **Arena:**
  - Leads with the next encounter: large artwork, what it tests, status as icon plus text (Available / Unlocks at Level N / Defeated), a Challenge button and Practice.
  - Every boss can be opened from the "All encounters" grid.
  - Rank, missions, achievements and seals sit in a quieter record section underneath.
  - Challenge rules and unlock logic are unchanged; the unlock check now ignores Real-World scenarios.
- **Campaign entrance:**
  - Hall artwork with the title and the first two sentences of the existing story setting.
  - Your current mission, or the starting mission for a new player, and one Start/Resume button.
  - Three facts: how a mission works, what carries over, and that decisions are final.
- **Lessons:**
  - The 33 equal boxes became a level list grouped by exam domain. The current group is open; the others are collapsed with "X of N" counts.
  - On phones, the list sits behind a "Change level" button.
  - Lesson text runs at a 66-character line length, with section headings, a cleaner terms list, a stronger exam-trap callout, a "Quick review" link to that level's Pocket Notes and flashcards, and "Check yourself".
- **Study navigation:** grouped into Learn (Lessons, Notes & cards), Practice (Practice, Acronyms, PBQs, Mock exam) and Build (Question Lab).
