# 2.4.0: Security+ review fixes applied

The automated review of the Security+ content (levels 13-32, recorded in `docs/review/sec-1..4.json`) found 156 issues: 3 wrong, 7 ambiguous, 84 giveaway and 62 minor. All 156 are now applied, by four parallel workers (one per batch file), each limited to its own files. Every fix that a worker wrote itself, rather than copying the suggestion, is listed in that worker's report and summarized below.

## Notable decisions
- **Giveaways:** distractors are now rewritten from the same topic. The yn sets vary their true/false counts and use near-miss false rows. Correct-is-longest across all scenarios dropped from 27% to 21%.
- **Practice twins:** the app can't exclude scenario IDs from a check pool, so guided practice and casebook cases that duplicated scored scenarios got new situations instead.
- **RTO/RPO:** these moved to objective 5.2 with domain "5 Program mgmt" (batch 2). Sample figures now vary (for example a 1-hour RTO with a 10-minute RPO; an 8-hour RTO with a 1-hour RPO), so the numbers no longer give the answer away.
- **Level 19 casebook:** the cross-file giveaway reported in batch 2 was already resolved by batch 1's rewrite of those cases.
- **Copilot commit `28959fc`** ("Reduce giveaway answers…"): this is superseded and won't be merged. It predates the review, was never checked, and rewrites SC-900 scenarios that had been checked against Microsoft Learn. Its `tools/check-giveaways.js` is worth reviving later as a lint.

## Checks run
- `node tools/check-content.js`: all blocking checks pass.
- Every scenario has `no.length == o.length-1`, and every lesson practice and casebook question has exactly one correct option.
- No em-dashes.
- Browser smoke test: all 20 Security+ levels, 103 lesson sections walked and 60 exam-style items answered, with no page errors.
