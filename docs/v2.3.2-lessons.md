# v2.3.2: Interactive lessons for SC-900 Levels 7–12

Every SC-900 level now has an interactive lesson. Lesson content lives in `data-lessons-3.js` and uses the same section components as `data-lessons-2.js` (`facets`, `compare`, `steps`, `casebook`, `check`). No lesson has its own page code, and the classic lesson view is still available from each lesson's footer.

## The six lessons
| Level | Sections and interactions |
|---|---|
| 7 Azure infrastructure security and Defender for Cloud | Four network controls (compare: DDoS Protection, Azure Firewall, Web Application Firewall, network security groups) · Inside the network (facets: virtual networks and subnets, Bastion, just-in-time access, Key Vault) · Microsoft Defender for Cloud (facets: posture management, workload protection, DevOps security) · How your secure score improves (steps) · Check (6) |
| 8 Microsoft Sentinel and Defender XDR | SIEM, SOAR and XDR (compare) · How Microsoft Sentinel works (steps) · Know each Defender by what it guards (facets) · Vulnerabilities, threat intelligence and the portal (facets) · Two that get swapped (compare: Defender for Identity vs ID Protection) · Check (6) |
| 9 Microsoft Purview: trust, compliance and protecting data | Trust and privacy (facets) · Compliance Manager (steps) · Know your data (facets) · Protect your data (compare: sensitivity labels vs data loss prevention) · Check (6) |
| 10 Microsoft Purview: retention, insider risk, eDiscovery and audit | Keep or delete (compare: retention policy, retention label, record) · Insider risk management (steps) · eDiscovery (steps) · Audit (compare: Standard vs Premium) · Check (6) |
| 11 Full SC-900 review | Guided review casebook: 10 cases (5 security solutions, 3 compliance, 2 core concepts), each linked back to its lesson section and Pocket Note · Independent check (10, drawn from every lesson level) |
| 12 SC-900 exam day | Your exam day plan (steps) · Clue word to product (facets, one per exam area) · Final warm-up (10) |

Levels 7 and 8 follow Calder Freight, a fictional shipping company. Levels 9 and 10 follow Juniper Legal Aid, a fictional nonprofit.

## Practice and assessment
- Guided practice and the Level 11 casebook are memory only: no attempts, review entries, XP or unlock changes. The test confirmed this after working through every section of every new lesson.
- Check yourself is scored and saved under `lesson-check-<level>`. The lesson and Pocket Notes are hidden while you answer.
- `data-cn-sc-checks-2.js` adds 10 check scenarios for Levels 7–10 (`rw.sc.*` ids, pack `sc-2-chk`), so each check has items the guided practice didn't just show.
- Only the level quiz unlocks the next level. Nothing here adds a requirement.

## Corrections shipped with the lessons
- **Level 9, privacy.** Microsoft Learn's unit "Describe Microsoft's privacy principles" now describes four areas (data control, data location, data security, data defense). The app taught an earlier list of six. Changed: questions `9-p0` and `9-q7` (overlay `QFIXES4`, same question keys), the Level 9 classic key point (`DAYFIXES`), the `privacy-principles` Pocket Note and its flashcards, and one Real-World scenario. The six are still mentioned, labelled as an older list, because older practice questions use them. That list is not on Microsoft Learn; the Pocket Note cites Microsoft's 2016 announcement for it.
- **Level 12, exam numbers.** 45 minutes to answer inside a 65-minute appointment; pass at 700 on a 1–1,000 scale; no penalty for a wrong answer.
- **Level 8, wording.** "Threat intelligence" follows the study guide bullet "Describe Microsoft Threat Intelligence".
- `DAYFIXES` is a new overlay: it replaces the text of one key point in a level's classic lesson, matched by heading. The original data files are unchanged.

## Known limits
- Reviewers read Microsoft Learn through a page reader that returns extracted text, not raw HTML. Key quotes were requested twice.
- Level 9's footer says the lesson was checked against Microsoft Learn. One sentence in it (the older six principles) rests on a Microsoft blog post instead.
- "A blank earns nothing" (Level 12) is an inference from Microsoft's "no penalty for guessing", not a quoted statement.
- The Level 11 casebook has no Microsoft Entra case. The independent check that follows draws from every level, including the Entra ones.
- Study advice in Level 12 (rest the day before, don't change confident answers) is advice, not a Microsoft fact.
