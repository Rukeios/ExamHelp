# v2.2.3: Interactive lessons for Levels 2–6

This release follows the v2.2.2 Security basics pilot. Lesson content lives in `data-lessons-2.js`, and `index.html` renders it with shared section components. No lesson has its own page code.

## Section types (reusable)
- **Existing:** `facets` (pick one of several parallel ideas), `models`, `layers` and `check`.
- **New in this release:**
  - `compare`: a table of options against criteria. The selected column is explained and highlighted. On narrow screens only the selected column shows.
  - `map`: identities placed in zones. The relationships are also written out as plain text, so the diagram doesn't depend on seeing it.
  - `steps`: an ordered walk-through.
  - `casebook`: short guided review cases, one at a time, with links back to the lesson section and its Pocket Note.
- **Optional fields on any section:**
  - `caution`: a "Watch out" note where shorthand would mislead.
  - `note`: the section's Pocket Note. It can be a concept (`sc.*`) or a comparison card (`cmp.*`).

## Practice and assessment
- **Guided practice and the review casebook** are memory only:
  - no attempts, review entries, XP or unlock changes
  - the test checked this before and after every lesson
- **Independent checks:**
  - The lesson and Pocket Notes are hidden during the check, and explanations come afterward.
  - Questions are drawn from scored Real-World scenarios, never the guided ones.
  - Selection takes one question per level first (on the review checkpoint), then covers each unseen concept, then fills. Unseen questions come first, and nothing repeats within a check.
  - Results are saved as normal scored practice under `lesson-check-<level>`.
- **Unlocks:** neither checks nor sections affect unlocking. Each lesson's last step still shows the single level quiz. Its mode follows prestige: Think on the first run, Blitz from Prestige 1, Written from Prestige 4. This was verified in v2.2.2 and left unchanged.
- **New scored scenarios:** 11 were added in `data-cn-sc-checks.js`. They fill gaps in the pool: encoding vs encryption, auditing, data in transit, tenants, user-assigned managed identities, Windows Hello for Business, SSPR writeback, smart lockout, sign-in risk, report-only mode, and roles vs Conditional Access. Every question has a stable ID and concept tags.

- **SSPR licensing:** the Learn pages checked don't state licensing for SSPR or password writeback, so the lessons make no licensing claim there.
- **Study guide date:** the fetched SC-900 study guide reported an unusual "skills measured" date. The outline content matched what the lessons use.
- **Level 6 classic view:** its original text still says "Run it three ways" (Think, Blitz, Written). It's study advice, not a requirement, and the data files are read-only. RJ to decide whether to reword it in an overlay.
- **Verified ID and Global Secure Access:** both are in the original Level 5 lesson but not in the current SC-900 skills outline. They're labelled that way.
