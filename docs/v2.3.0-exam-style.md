# v2.3.0: exam-style questions, closer mock, level steps

## Exam-style questions

Content: `data-xf-sc.js` (`window.XF_PACKS`). 62 SC-900 items: 24 Yes/No sets, 16 drop-down, 11 choose two, 11 matching.
The correct answer is always first in the data and shuffled at render (Yes/No rows are shuffled too).

| Type | Data | Points |
|---|---|---|
| `yn` | `rows: [[statement, true/false, why]]` | one per statement |
| `dd` | `text` with `[1]`, `[2]`; `blanks: [[correct, wrong, wrong]]` | one per blank |
| `multi` | `o: [...]`, first `n` are correct | one per correct choice |
| `match` | `pairs: [[description, name]]`, `extra: [unused names]` | one per match |

Each item is indexed in `Q` with `xf` set. `coreQ()` excludes them, so bosses, the campaign, the diagnostic,
Blitz and Written are unchanged. They are added only to: Think-mode level quizzes, review, Practice → Exam-style,
the per-level Exam-style step (`xf-day-<level>`), and the SC-900 mock.

Scoring in quizzes is fractional per question (2 of 3 statements = 0.67). The mock counts points: one per
multiple-choice question and one per correct selection, and the percentage is points earned over points available.
Microsoft doesn't publish how the real exam weights multi-part questions beyond "each correct selection is worth
one point", so treat the mock percentage as a guide.

## SC-900 mock

- 45 minutes (Microsoft's exam time for fundamentals exams; seat time is 65).
- 50 questions (Microsoft says most exams have 40 to 60): Concepts 6, Entra 14, Security solutions 19, Compliance 11,
  following the skills-measured weights. 20 are exam-style (2 / 6 / 8 / 4).
- Not modelled: drag and drop (matching uses drop-downs, which work by keyboard and on phones), hot area, case studies.

## Level steps

Lesson → Microsoft Learn (or videos) → Pocket Notes → Flashcards → Check yourself → Exam-style → Level quiz.
A level shows only the steps it has. Steps are guidance; the level quiz alone unlocks the next level.
Opening the course link and the notes is remembered in `ui.steps` (saved with view preferences, included in backups).
Flashcards count as done when every card for the level has been rated once.

Course links: `data-links.js`. Module and learning-path URLs were opened on 2026-10-02 and titles copied from the pages.

## Sources and review

An independent automated review checked all 62 items against Microsoft Learn on 2026-10-02 (pages read through
a fetch tool that returns extracted text, not raw HTML). Result: no wrong answers; one outdated explanation
(privacy principles) rewritten; 4 ambiguous items reworded; 14 answer giveaways removed; 11 minor wording fixes;
10 Yes/No rows replaced or added so the Yes/No mix varies (13 sets with two Yes, 6 with two No, 3 all Yes, 2 four-row).
Source URLs per level are in `data-xf-sc.js` (`srcByLevel`).

The skills outline dated October 21, 2026 was read on 2026-10-02. It does not list Security Copilot, Entra Agent ID,
Security Exposure Management, adaptive protection, Global Secure Access or Verified ID, although the Learn modules
now have units on them.

## Unresolved
