# CertificationNation v2.1.0: Study Your Way

This is the release package for v2.1.0: the audit, the content model, coverage, the brand
checklist, acceptance tests with results, and the release notes. It was built directly on
`release/v2.1.0` rather than as Copilot prompts, so every item below is working code, not
a plan.

## 1. Audit: what 2.1 reuses

| Existing system | Where | How 2.1 uses it |
|---|---|---|
| Question index `Q` (answer at index 0, shuffled at render) | `index.html`, question index | Real-World scenarios register into `Q` as `rw.*` keys, so quizzes, review, weak spots, report-a-problem and backups all work unchanged |
| Pool builders (`keysFor`, scopes, bosses, mocks, diagnostic, evidence) | `index.html` | Filtered with `coreQ()` so scenarios never enter level quizzes, bosses, mocks, the diagnostic or coverage. v2.0.1 behavior is unchanged |
| Review scheduler (`REVIEW_DAYS` 1/3/7/14, once-per-day advance) | `recordReview` | Scored scenario answers use it directly. Flashcards use the same intervals in a **separate** store (`state.cards`) so self-ratings never touch accuracy |
| Study sub-navigation (`STUDY_TABS`) | `renderStudyNav` | One new Study tab, **Notes & cards**, holds Pocket Notes, Flashcards, Don't Mix These Up, My Field Guide and 5-Minute Sprint. No new top-level tab |
| Full backup (schema 4 → 5) | `buildBackup`, `validateBackup`, `restoreBackup` | New learner state lives inside `state`, so it's backed up automatically. Schema 4 and older ExamHelp backups still restore |
| Effects (`queueFx`, `ExamHelpFX`) | `runFx` | Stamps and sprint completion reuse `victory`. Both the kit and the boosts already skip motion under reduced-motion |
| Partial-session rules (v2.0.1) | `finish`, `renderResult` | Flashcard and sprint summaries follow the same rule: "Session ended early: X of Y" |
| Campaign lock | `renderCore` | Notes & cards lives in Study, which campaign mode can't reach, so no new mode can bypass campaign decisions |

## 2. Content model

Three data modules, loaded before the app, each pushing a pack onto `window.CN_PACKS`:

- `data-cn-sc.js`: **concepts** (Pocket Note + recall cards)
- `data-cn-compare.js`: **comparisons** (shared across certifications)
- `data-cn-sc-scenarios.js`: **scenarios** (Real-World Practice)

One concept is the single source for its note, its flashcards and its Field Guide bookmark.
Comparisons and scenarios link to concepts by id. Ids are permanent: fix text in place and
bump `v`, never renumber. Bookmarks and schedules then follow corrections automatically.

```js
// concept
{ id:"sc.device-identity", cert:"sc", day:3, dom:"Entra", obj:"2.1", objTitle:"…", topic:"…",
  title:"Device identities",
  lines:["…","…","…"],            // 3-5 short lines, ≤60 words total
  clue:"…",                       // one-line exam clue
  except:"…",                     // optional: only when a shortcut would mislead
  more:"…",                       // optional: "Explain more", collapsed
  cards:[{id:"sc.device-identity.c1", kind:"term"|"use", q:"…", a:"…"}],
  src:["https://learn.microsoft.com/…"], reviewed:"2026-09-30", status:"source-checked", v:1 }

// comparison
{ id:"cmp.hash-encrypt", certs:["sc","sec"], title:"…", sides:[{name,is}],   // 2-3 sides
  distinction:"…", clue:"…", apply:"…", notIt:["why side A doesn't fit the example", …],
  concepts:["sc.hashing","sc.encryption"], pendingConcepts:[],   // ids from future batches
  src:[…], reviewed, status, v }

// scenario (registered into Q as a scored question)
{ id:"rw.sc.devices.next", concept:"sc.device-identity", concepts:[…], cmp:"cmp.device-join"|null,
  day:3, dom:"Entra", obj:"2.1", type:"identify"|"next"|"constraints", diff:1|2|3, setting:"school",
  s:"situation, 2-4 sentences", q:"question", o:[correct, d1, d2, d3],   // correct at index 0
  why:"…", no:["why d1 doesn't fit", "…", "…"], take:"copyable takeaway" }
```

`obj` is CertificationNation's numbering of Microsoft's published SC-900 skills outline
(Microsoft doesn't number the bullets); `objTitle` carries Microsoft's wording.

**Learner state** (all inside `state`, so it's in full backups):
`bookmarks {id: {t, note}}` (personal notes are kept apart from authored content),
`cards {cardId: {stage, due, last, lapses, n, lastGot}}`, `stamps {day: ts}`,
`titles {id: ts}`, `activeTitle`, `milestones {later, sprints}`,
`study {flash, sprint}` (interrupted sessions).

**Validation**: `node tools/check-content.js` blocks on duplicate ids, broken links, notes over
5 lines or 60 words, missing sources or review dates, scenarios without four options or three
distractor reasons, a correct option more than 25 characters longer than every distractor, and
the correct option being the longest in more than 40% of scenarios. It's at 19% now.
`--manifest` rewrites `COVERAGE.md`.

**Review status, honestly:** SC-900 content was drafted with AI help, then checked against
the linked Microsoft Learn pages by a separate automated review pass that hadn't seen the

Reference section.

(threat/vulnerability/risk, IDS/IPS, RTO/RPO).

## 6. Release notes (v2.1.0)

These are the in-app patch notes (`data-patchnotes.js`), and they describe only completed work:

- ExamHelp is now CertificationNation. All progress, campaign decisions, rewards and backups carry over, and old backup files still import.
- **Notes & cards** in Study: Pocket Notes for every SC-900 lesson (61 concepts) with exam clues and Microsoft Learn sources.
- **Flashcards** from the same notes, rated Again / Almost / Got it. They're scheduled separately from quiz scores.
- **Don't Mix These Up**: 19 comparisons.
- **Real-World Practice**: 78 SC-900 workplace scenarios, each explaining why the other options don't fit.
- **My Field Guide**: saved items, search, your own notes, copy and print.
- **5-Minute Sprint**: 3 notes, 3 cards, 1 scenario, with no countdown.
- Deck stamps, cosmetic titles and a later-day recall milestone, none of which add XP. Night Shift is retired.
- Security+ content arrives in batches. The content is AI-assisted and automatically source-checked, but not yet expert-reviewed.
