# v2.3.1 review: Security+ content (2026-10-02)

The Security+ drop (levels 13-32) was drafted with AI help and marked `status: "drafted"`. Before it shipped, four independent
automated reviewers read every item and wrote their findings to `docs/review/sec-1.json` to `sec-4.json`. Each finding has the
file, the item id, the problem and an exact replacement. Pages were read through a fetch tool that returns extracted text, and
CompTIA's objectives PDF could not be opened, so objective numbers rest on Professor Messer's course index.

No keyed answer was wrong in any batch. Port numbers, firewall rule logic, incident response order and the ALE arithmetic all checked out.

## Fixed in this release

- **False source claims (app code).** Every Security+ lesson footer said "Content checked against Microsoft Learn", and every Security+ note's Reference line said "Checked against these sources by an automated review". Neither was true. The footer and the Reference line now follow the data: drafts say they are drafts.
- **3 wrong:** lesson 21 feedback said a screened subnet is safer than the internal LAN; lesson 20 filed multicloud under hybrid; `rw.sec.mobile.constraints` defined CYOD backwards.
- **7 ambiguous:** open storage bucket re-keyed to misconfiguration (scenario, lesson 19 case, Pocket Note line); typosquatting examples that used a host under the real domain; hybrid cloud wording; `xf.sec.ir.dd` (several true answers); lesson 28 decentralized example; `xf.sec.documents.match` policy example; `rw.sec.compliance.identify` due diligence stem.
- **Layout:** long drop-down options overflowed on phones; long video lists (up to 16) now fold so the next step stays in view.

## Not fixed yet (use the JSON files)

- **84 giveaways.** About half the scenarios use distractors from unrelated topics, so they can be answered by elimination. All 19 Yes/No sets but two are two-true-one-false with an absurd false row. Replacement options and rows are in the JSON.
- **Guided practice repeats the scored check.** Many lesson practices are close paraphrases of scenarios that the same lesson's Check yourself then scores (the pairs are listed in the JSON). This breaks the rule that independent checks use different scenarios.
- **62 minor:** objective-number slips (RTO/RPO are 5.2, not 3.4; rules of engagement is 5.3), a few wrong source videos, SY0-701 terms missing from Zero Trust (control plane, policy engine, policy enforcement point), acronym expansions.
- **Coverage gaps** against the objectives are listed in each JSON file's `notes`.

Status stays `drafted` until those are applied and a human has reviewed the content.
