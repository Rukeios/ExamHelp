# v2.2.2: Interactive lesson pilot (Level 1, Security basics)

## What it is
Level 1 is now an interactive lesson in five sections: CIA triad, shared responsibility, defense in depth, Zero Trust, and Check yourself. Every other level keeps the 2.2 layout until this pilot is reviewed.

## Content and presentation are separate
- The content lives in `data-lessons.js` (`window.LESSON_PILOTS[day]`).
- `index.html` renders it with `renderLessonPilot()`.
- Each section chooses the interaction that fits its topic:
  - `facets`: a few parallel ideas, one shown at a time.
  - `models`: one table seen through different options.
  - `layers`: an ordered stack.
  - `check`: the independent check.
- New interaction types can be added without forcing every topic into the same shape.
- `concept` links a section to its existing Pocket Note (`data-cn-sc.js`). Saving uses the same Field Guide bookmarks, which are already included in backups.
- `careers` is `null`. The "Where this skill is used" box only renders when reviewed, sourced entries exist.

## Assessment rules
- **Guided practice** (the panel beside each section) is in-memory only:
  - no attempts, review entries or XP
  - no effect on readiness or unlocks
  - the panel tells the learner this
- **Check yourself** hides the instructional content and draws four *different* scored Real-World scenarios for the level (one from each concept group, unseen ones first). These are saved as normal scored practice under `lesson-check-<day>`.
- **Unlocking:** one level quiz per level, in the mode set by prestige (Think on the first run, Blitz from Prestige 1, Written from Prestige 4; review levels Written from Prestige 2). Shown on the final section as "Level quizzes". This replaced the three-mode requirement in the same release.

## State
`ui.pilot[day] = {sec, pick:{sectionId: optionId}}` and `ui.sel` are saved with the UI preferences, so the learner's place survives a reload. Lesson IDs, saved progress and backups are untouched. "Switch to the classic lesson view" (`ui.classicLesson`) restores the previous layout.

## Accessibility
- Options are ARIA tabs with arrow keys, Home and End. Layers use vertical arrows.
- Practice answers are buttons with `aria-pressed`, and feedback is announced through a live region.
- Focus moves to the section heading when the section changes.
- Reduced motion turns off the reveal animations.
- On narrow screens the level list collapses, and the page stacks in order: concept, practice, note, next.

## Verified (headless Chromium)
- Concept switching by click and keyboard.
- Wrong and right answer feedback.
- Saving a note, which creates a bookmark and nothing else (0 attempts, 0 review entries, 0 XP).
- Reloading keeps the section and selection.
- The check page hides the lesson; the scored check saves one `lesson-check-1` attempt and doesn't mark the level done.
- Classic view toggles back and forth.
- 390px light and dark, plus 1280 and 1440 desktop, with no horizontal overflow.
- Earlier regression suites: early-end banner, boss win, legacy profile and backup restore, campaign lock, lesson keyboard focus.
