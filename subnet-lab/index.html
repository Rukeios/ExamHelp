The easy method: the magic number

No binary needed for most exam questions. Learn one row of numbers and count.

  1. Find the octet the slash lands in. /25 to /30 lands in the 4th octet. /17 to /24 in the 3rd. /9 to /16 in the 2nd.
  2. Get the magic number (block size). It's 256 minus the mask number in that octet, or just read it off the table. Every time the slash goes up by one, the block halves.
  3. Count up by the block size from 0: 0, 32, 64, 96… Stop at the last number that isn't bigger than your IP's number in that octet. That's the network address.
  4. Next block minus 1 is the broadcast. Everything between them is usable. Hosts = 2 to the power of host bits, minus 2. In the 4th octet that's simply block size minus 2.
Worked example: 192.168.10.77/27
/27 lands in the 4th octet. Block size 32.
Count: 0, 32, 64, 96. 77 sits in the 64 block.
Network 192.168.10.64 · Broadcast 192.168.10.95
Usable .65 to .94 · 30 hosts

Exam shortcut: if a question gives a mask like 255.255.255.224, the magic number is 256 − 224 = 32. Same answer, no table.

The only table you need

4th octetMaskBlockHosts

Same block sizes one octet over: /17 = 128, /18 = 64, /19 = 32, /20 = 16, /21 = 8, /22 = 4, /23 = 2, /24 = 1. Mask numbers to know cold: 128, 192, 224, 240, 248, 252, 254, 255.
